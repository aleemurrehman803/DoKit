      How to resize images in bulk

      1. Upload your images

        Drag & drop one or many PNG, JPEG, or WebP files (up to 25 MB each) into the box, or click to browse your files.

      2. Crop or clean up (optional)

        Open any image in the editor to crop it, remove its background, or erase parts by hand.

      3. Set the size

        Type exact pixel dimensions or a percentage. Keep the aspect-ratio lock on to avoid stretching. Optionally set a target file size in KB.

      4. Download

        Process all, then download each image separately — or everything together as a ZIP, watermark-free.

      Pro tips

      • Resize before you upload Websites rarely display images wider than 1600 px, so downsizing first makes pages load faster and uploads finish sooner — with no visible difference.
      • JPEG for photos, PNG for graphics JPEG at quality 85–90 keeps photos small and crisp; PNG stays sharp for logos and screenshots with text. WebP usually beats both on file size.
      • Hit an exact KB target Need “under 100 KB” for a form? Type 100 in the target-size box — the tool auto-tunes JPEG/WebP quality to fit, so you don't have to guess.
