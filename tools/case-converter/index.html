Pro tips

  • Title Case for headings, Sentence case for body Use Title Case for titles and headings, and Sentence case for descriptions and paragraphs — it matches professional publishing style.
  • UPPER is for shouting, lower is for slugs UPPERCASE reads like shouting in chats and emails — use it sparingly. lowercase is perfect for URLs, file names, and hashtags.
