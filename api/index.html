DoKit API

The planned DoKit API. It is not live yet — this page documents the interface so integrations can be planned.

Base URL: https://api.dokit.app/v1

Quickstart

Requests use JSON. Responses are JSON. See Authentication for how access is granted.

Authentication

API calls use a personal API key sent in the request. Key creation and management open with the backend in Phase 3. See API keys.

Endpoints

MethodEndpointWhat it does
POST/image/resizeResize an image (PNG, JPEG, WebP).
POST/image/compressCompress an image, optionally to a max KB size.
POST/image/convertConvert between PNG, JPEG and WebP.
POST/text/wordcountCount words and characters in text.
POST/text/caseconvertConvert text between case styles.
GET/typing/leaderboard?game=battle&limit=10Top battle players.
GET/user/profileAccount profile (requires sign-in).

Rate limits

Rate limits apply per API key. Exact limits are published when the API launches.

Error codes

Errors return a standard JSON error response with a code and a message.

Webhooks

Webhooks are planned for the future. They are not available yet.

Phase 3 note: API access needs the backend. Live data arrives with the self-hosted backend in Phase 3 — nothing here is faked, and nothing you type is sent anywhere.
