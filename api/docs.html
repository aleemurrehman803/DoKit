⚡ Quickstart

Install the SDK (or copy js/dokit-sdk.js into your project):

// Node.js
const DoKitSDK = require("./dokit-sdk.js");
// Browser: <script src="https://aleemurrehman803.github.io/DoKit/js/dokit-sdk.js"></script>
// → window.DoKitSDK

const dokit = new DoKitSDK({ apiKey: "dk_YOUR_KEY" });

// Count words
const stats = await dokit.countWords("Hello world");
// → { words: 2, characters: 11, charactersNoSpaces: 10,
//     sentences: 1, readingTimeSec: 1 }

// Compress an image (browser File / Node Buffer)
const small = await dokit.compressImage(file, { quality: 0.8 });
// → Blob of the compressed image

Get a key: Account → API Keys (sign in required).

🔐 Authentication

Every request carries your key in the Authorization header:

Authorization: Bearer dk_9f3K…xQ2a
  • Keys start with dk_ and are 35 characters long.
  • DoKit stores only a SHA-256 hash of your key — a leaked database reveals nothing usable.
  • Use one key per app. Revoke a key the moment it leaks (API Keys).
  • Never put a key in client-side code that ships to browsers you don't control — call the API from your server.

⏱️ Rate limits

PlanRequests / dayBurst
Free10010 / minute
Pro ($6/mo)10,000120 / minute
Team ($29/mo)100,000600 / minute

Over the limit you get 429 with a Retry-After header (seconds). The SDK surfaces it as err.retryAfter:

try {
  await dokit.countWords(text);
} catch (err) {
  if (err.code === "rate_limited") {
    console.log("Slow down, retry in", err.retryAfter, "seconds");
  }
}

Rate limits are counted per API key, reset daily at 00:00 UTC.

🔌 Endpoints

Base URL: https://api.dokit.app/v1

POST /image/resize

Resize an image. Multipart upload (image field). Returns the resized image (binary).

# fields
image    (file, required — png/jpeg/webp, ≤ 25 MB)
width    (int, px — width or height required)
height   (int, px)
fit      "cover" | "contain" | "fill" (default "cover")
format   "png" | "jpeg" | "webp" (default "png")

POST /image/compress

Compress an image. Returns the compressed image (binary).

# fields
image      (file, required)
quality    (float 0–1, default 0.8)
maxSizeKB  (int, optional — iteratively compress until under this size)

POST /image/convert

Convert between PNG, JPEG, and WebP. Returns the converted image (binary).

# fields
image   (file, required)
format  "png" | "jpeg" | "webp" (required)

POST /text/wordcount

JSON body: { "text": "…" } (max 1,000,000 chars).

→ 200 OK
{
  "words": 2,
  "characters": 11,
  "charactersNoSpaces": 10,
  "sentences": 1,
  "readingTimeSec": 1
}

POST /text/caseconvert

JSON body: { "text": "…", "mode": "upper|lower|title|sentence|alternating|inverse" }

→ 200 OK
{ "result": "HELLO WORLD" }

GET /typing/leaderboard?game=battle&limit=10

→ 200 OK
{
  "entries": [
    { "rank": 1, "username": "speedy", "wpm": 112, "accuracy": 98.2 }
  ]
}

GET /user/profile

Returns the profile of the API key owner.

→ 200 OK
{ "userId": "abc123", "plan": "free", "credits": 250 }

❌ Error codes

HTTPcodeMeaning
400invalid_argumentBad input (e.g. unknown format, empty text)
401unauthorizedMissing/invalid API key
401key_revokedKey was revoked — generate a new one
403plan_requiredEndpoint needs Pro/Team
413file_too_largeImage over 25 MB
429rate_limitedToo many requests — honor Retry-After
500internal_errorSomething broke on our side — retry later

Error body shape:

{ "error": { "code": "rate_limited", "message": "Daily quota exceeded" } }
